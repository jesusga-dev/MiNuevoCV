Sastrería, marroquinería y relojería

Entorno de demostración. Hasselhoff es una tienda ficticia creada para ejercitar tareas reales de soporte N1. El catálogo alimenta los mismos datos que consulta el panel: si cambiás un ticket, las métricas se recalculan. Nada se envía a un servidor; todo corre en tu navegador.

Catálogo

Ropa de hombre, carteras y relojes. El estado de stock que ves acá es el que devuelve la tabla productos en la consola SQL del panel.

Panel de soporte N1

Las cuatro tareas que ocupan el día de un analista de primer nivel: atender la cola de tickets, consultar la base para entender qué pasó, leer los logs del servicio y vigilar las métricas.

Hasselhoff — entorno de práctica construido con HTML, CSS y JavaScript, sin dependencias ni backend. Volver al CV · Curso de Soporte N1
